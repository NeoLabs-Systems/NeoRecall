# NeoRecall engineering guidelines

NeoRecall follows the NeoLabs-Systems Node/Flutter conventions. Keep backend modules small and layered as `routes → services → database/utilities`. Use parameterized SQL exclusively. Database migrations are append-only and numbered.

Reliability and privacy outrank throughput. No transcript receipt may become terminal until derived rows are durably committed and the temporary server audio file has been unlinked. No server feature stores or serves audio after processing.

Language behavior must be model-driven and multilingual. Do not add phrase lists or scenario-specific filters. Put tunable numeric thresholds in validated configuration.
