Privacy by lifecycle

The receipt proves the audio is gone.

The client retains each chunk until transcript data is durably committed and the server confirms its temporary file was deleted. NeoRecall stores transcripts, speaker embeddings, memories, and search vectors—not server-side audio.

  1. 1Capture into a durable local queue
  2. 2Upload idempotently with SHA-256
  3. 3Persist transcript with full SQLite durability
  4. 4Delete server audio, issue receipt, release client copy
Built for real days

Useful detail without constant token use.

Memories and mini-memories

Meetings and important conversations become episodic memories. Facts, people, tasks, promises, events, and relationships remain atomic and easy to act on.

English memory layer

Original-language transcripts stay intact while consolidated memory text is normalized to English for consistent recall across German and English days.

Visible, consent-aware recording

First-run consent guidance, persistent indicators, and immediate pause controls keep capture explicit. NeoRecall does not include a covert mode.

Self-host in minutes

One service. Your machine.

Setup downloads pinned local models, verifies native inference and sqlite-vec, then installs a user service. Docker Compose is available as an alternative.

npm i -g neorecall
neorecall install
neorecall setup
neorecall start
